⚖️ PrisonFace: Next-Gen Inmate Management & Biometric SecurityPrisonFace is a high-performance, local-environment desktop application engineered to digitize and secure correctional facility operations. Built with a heavy-duty JavaFX core and integrated with OpenCV AI, this isn't just a database—it’s a proactive security layer for modern law enforcement.

⚡ The "Secret Sauce"While most management systems rely on manual data entry, PrisonFace utilizes a Python-driven Biometric Recognition Engine. By leveraging Computer Vision (OpenCV), the system can instantly identify inmates, reducing human error and preventing identity fraud within the facility.

🛠 Tech StackThe Brains: Java (Robust backend logic)The Face: JavaFX & CSS (Modern, dark-themed, intuitive UI)The Memory: MySQL (Relational data integrity for massive record-keeping)The Vision: Python + OpenCV (AI-powered face recognition module)

🚀 Key FeaturesBiometric Identification: Real-time facial scanning for inmate check-ins and transfers.Inmate Lifecycle Tracking: From intake to release, track every cell assignment, medical record, and visitor log.Automated Record Generation: One-click PDF report generation for legal documentation.Secure Local Storage: Designed for 100% internal usage—zero external cloud dependency for maximum data privacy.Administrative Command Center: A centralized dashboard for warden-level oversight.
